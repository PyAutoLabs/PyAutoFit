========================================
Choosing a search: the capability matrix
========================================

Every one of **PyAutoFit**'s 15 non-linear searches declares its capabilities as class attributes (``autofit.Nautilus.jax_use``, ``autofit.Emcee.posterior_kind``, ...). The tables below are generated from those declarations, through the versioned search manifest (``search-manifest@1``)::

    python -m autofit search-manifest --json

The same flags are enforced at run time: a search whose ``jax_use`` is ``required`` raises ``SearchException`` before fitting when the analysis is not JAX (``Analysis(use_jax=True)``).

These are **static** capabilities, a property of the search class. What one run delivers can be narrower: ``SMC`` estimates the evidence only when it starts from a prior-sampling initializer, not from a warm start.

The invalid value is what the backend actually sees, not yet normalised. For the ``neg2_log_posterior`` minimizers it is conditional: a NaN or infinite likelihood is replaced by ``-inf`` and then multiplied by -2 into ``inf`` (the value listed), while a model rejected by a ``FitException`` or a failed assertion returns ``-inf``.

Emcee, BlackJAXNUTS and SMC keep their archive after a fit completes whatever the ``output.search_internal`` config says, because their samples cannot be rebuilt without it.

Column meanings
---------------

- **JAX**: ``none`` (the backend never needs JAX), ``optional`` (a jitted or batched fast path when the analysis is JAX) or ``required`` (the backend cannot run without a traceable JAX likelihood).
- **Gradients**: ``uses`` when the backend differentiates the likelihood.
- **Batched**: the backend evaluates a vectorised (``jax.vmap``) likelihood over many points at once.
- **Posterior**: ``chain`` (equally weighted MCMC draws), ``weighted`` (weighted samples) or ``point`` (a point estimate).
- **Resumable**: an interrupted run resumes from its own checkpoint.
- **Warm start**: ``provider`` (starts cold and can seed another search), ``consumer`` (wants a warm start, e.g. from a provider's posterior) or ``neutral``.
- **Install**: ``base`` ships with ``pip install autofit``; ``autofit[optional]`` needs the optional extra.

See also the :doc:`search citations <citations>` page and the :doc:`API reference <../api/searches>`.
