# Community

**PyAutoFit** is built in the open by its users: everyone is welcome to ask questions, share what they have made with
it, and contribute. This page lists what the community has built on **PyAutoFit**, how to get help and how to contribute.

## Community contributions

Independent tools, tutorials, teaching material and the code behind papers built on **PyAutoFit**. They are maintained
by their authors and are not endorsed, tested or supported by PyAutoLabs; check each project's README and license.

### Get listed

Post your project in the [PyAutoLabs Discussions](https://github.com/orgs/PyAutoLabs/discussions) (Show and tell) and the maintainers will add it, or open a
pull request editing this page (`docs/general/community.md`).

## Get help & talk to us

Questions, ideas and bug reports go to the [PyAutoLabs Discussions](https://github.com/orgs/PyAutoLabs/discussions). Chat with the developers and other users
on [Slack](https://join.slack.com/t/pyautolens/shared_invite/zt-2cufp4eyf-fXfgMxRGuvg~bMrI3uOAxg).

## Contributing

Read the [PyAutoLabs contribution guide](https://github.com/PyAutoLabs/.github/blob/main/CONTRIBUTING.md) (one guide for every repository), the [Code of Conduct](https://github.com/PyAutoLabs/.github/blob/main/CODE_OF_CONDUCT.md) and the
[AI policy](https://github.com/PyAutoLabs/PyAutoScientist/blob/main/AI_POLICY.md) (AI-assisted contributions are welcome under it). Tutorial notebooks are generated from the `.py`
scripts in each workspace `scripts` folder, so edit those (the `# %%` marker alternates code and markdown cells), not
the notebooks. For hands-on help with a contribution, ask on the [PyAutoLabs Discussions](https://github.com/orgs/PyAutoLabs/discussions).
