===================
Non-Linear Searches
===================

A non-linear search is an algorithm which fits a model to data.

**PyAutoFit** supports 15 non-linear searches in three families: nested samplers (nest), Markov chain Monte Carlo (MCMC) and maximum likelihood / maximum a posteriori estimators (MLE). The :doc:`capability matrix <../searches/index>` compares them (JAX use, gradients, evidence, posterior kind, install) and the :doc:`search citations <../searches/citations>` page lists what to cite for each.

**Examples / Tutorials:**

- `readthedocs: example using non-linear searches <https://pyautofit.readthedocs.io/en/latest/cookbooks/search.html>`_.
- `autofit_workspace: simple tutorial <https://github.com/PyAutoLabs/autofit_workspace/blob/main/notebooks/overview/overview_1_the_basics.ipynb>`_
